# Integrate VSCode

Everything I’m doing here uses Git, but also ties into GitHub.

I open Visual Studio Code and select a folder which has an existing repo cloned from GitHub (__Second__).

I sign in and open a terminal window to __Output__.

I make a small edit to a file and click Save. The filename changes color, signalling that it has been changed.

<figure>
<img src = "https://jor-donegal.github.io/github26/images/fig20.jpg">
<figcaption>Fig 20. Change a file.</figcaption>
</figure>

I click on Source Control, and I can see the changed file.

<figure>
<img src = "https://jor-donegal.github.io/github26/images/fig21.jpg">
<figcaption>Fig 21. Source Control.</figcaption>
</figure>

I have options to discard (curvy arrow) or add (+), hover over them to distinguish. 

If I add, I can see a new tab, Staged Changes.

<figure>
<img src = "https://jor-donegal.github.io/github26/images/fig22.jpg">
<figcaption>Fig 22. Staged changes.</figcaption>
</figure>

If I click on the __Commit dropdown__ I can see the Git commands. I select __Commit__

Visual studio asks for a message to accompany the change.

<figure>
<img src = "https://jor-donegal.github.io/github26/images/fig23.jpg">
<figcaption>Fig 23. Comments.</figcaption>
</figure>

I then click the __Commit__ button. My local Git repo is now clean, but is one revision ahead of the origin, my GitHub repo. I can now Sync changes. But first, I select the Output screen of the terminal and select to show GIT.

<figure>
<img src = "https://jor-donegal.github.io/github26/images/fig24.jpg">
<figcaption>Fig 24. Synch.</figcaption>
</figure>

If I monitor the output, I can see the detail of the push to the repo.

<figure>
<img src = "https://jor-donegal.github.io/github26/images/fig25.jpg">
<figcaption>Fig 25. GIT log.</figcaption>
</figure>

And I can verify on GitHub.
